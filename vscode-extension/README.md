# OpenCode Human Bot

Deterministic coding assistance backed only by local source indexing and user-selected repository code. No AI APIs or models are used.

Install the Python project with its `codebot` extra, compile this extension with `npm.cmd install` and `npm.cmd run compile`, then package it with `npm.cmd run package`. See the workspace's `INSTALLATION.md` and `SECURITY.md` for setup and approval behavior.
